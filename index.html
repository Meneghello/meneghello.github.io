Publicador

Também identificado como DarkTube Publicador.

Este é o aplicativo de uso próprio do responsável pelo canal. Sua finalidade é preparar, enviar e organizar vídeos próprios no YouTube e no Instagram, com os textos e as capas escolhidos pelo operador.

A conexão com o YouTube utiliza os Serviços de API do YouTube. O titular autoriza o acesso na página do Google; a integração local utiliza a autorização para identificar o canal, consultar o processamento e realizar as operações de publicação permitidas.

As credenciais ficam no computador do operador. Este site apresenta o projeto e suas políticas: não recebe tokens nem oferece conexão de contas de visitantes.
